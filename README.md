# Веб-сервис для управления движением денежных средств (ДДС)

Веб-приложение для учета, управления и анализа поступлений и списаний денежных средств компании или частного лица.

## Возможности приложения

### Основные функции
- ✅ Создание, редактирование, удаление и просмотр записей о движении денежных средств
- ✅ Фильтрация записей по дате, статусу, типу, категории и подкатегории
- ✅ Управление справочниками (статусы, типы, категории, подкатегории)
- ✅ Логические зависимости между сущностями
- ✅ Валидация данных на стороне клиента и сервера

### Поля записей ДДС
- **Дата** - автоматически заполняется текущей датой, но может быть изменена
- **Статус** - Бизнес, Личное, Налог (расширяемый список)
- **Тип** - Пополнение, Списание (расширяемый список)
- **Категория и подкатегория** - иерархическая структура (расширяемые списки)
- **Сумма** - количество средств в рублях
- **Комментарий** - необязательное поле

### Логические зависимости
- Подкатегории привязаны к категориям
- Категории привязаны к типам
- При выборе типа фильтруются доступные категории
- При выборе категории фильтруются доступные подкатегории

## Технологии

- **Backend**: Python 3.x, Django 5.2.6
- **База данных**: SQLite (по умолчанию)
- **Frontend**: HTML, CSS (Bootstrap 5.3), JavaScript (jQuery)
- **Иконки**: Bootstrap Icons

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка базы данных

```bash
python manage.py makemigrations
python manage.py migrate
```

### 3. Создание суперпользователя (опционально)

```bash
python manage.py createsuperuser
```

### 4. Запуск веб-сервиса

```bash
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

### 5. Административная панель

Административная панель Django доступна по адресу: http://127.0.0.1:8000/admin/

## Использование

### 1. Настройка справочников

Перед созданием записей ДДС рекомендуется настроить справочники в следующем порядке:

1. **Типы** - создайте типы операций (Пополнение, Списание)
2. **Статусы** - создайте статусы (Бизнес, Личное, Налог)
3. **Категории** - создайте категории для каждого типа
4. **Подкатегории** - создайте подкатегории для каждой категории

### 2. Создание записей ДДС

1. Перейдите на главную страницу
2. Нажмите "Добавить запись"
3. Заполните форму:
   - Выберите тип операции
   - Выберите категорию (список фильтруется по типу)
   - Выберите подкатегорию (список фильтруется по категории)
   - Укажите сумму и другие поля
4. Сохраните запись

### 3. Фильтрация записей

На главной странице используйте фильтры для поиска нужных записей:
- По периоду дат
- По статусу, типу, категории, подкатегории

### 4. Управление справочниками

Перейдите в раздел "Справочники" для управления:
- Статусами
- Типами
- Категориями
- Подкатегориями

## Особенности реализации

### Валидация данных
- **Серверная валидация**: Проверка логических зависимостей между сущностями
- **Клиентская валидация**: JavaScript валидация обязательных полей

### Динамическое обновление форм
- При выборе типа автоматически обновляется список категорий
- При выборе категории автоматически обновляется список подкатегорий

### Адаптивный дизайн
- Использование Bootstrap 5 для создания адаптивного интерфейса
- Мобильная версия поддерживается

## API Endpoints

### AJAX endpoints
- `GET /ajax/get-categories/` - получение категорий по типу
- `GET /ajax/get-subcategories/` - получение подкатегорий по категории
